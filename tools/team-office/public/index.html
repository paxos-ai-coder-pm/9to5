                    What can the team do on my computer?

                    While it works, the team edits files inside the project's folder and runs the programs a project needs (for example Node.js, Python or npm to install and test things). It can't commit or publish to GitHub unless you start a run that says so. Those programs can do anything a program on your computer can do, so only build things you'd be happy to run yourself — and use ↶ Undo on a project card if you don't like a change.
